# ソニー損保 AI Market Twin ─ デモダッシュボード

提案資料「ソニー損保のPULLを科学する」⑤ **AI Market Twin — PULL施策をAI上で事前シミュレーションし、
打ち手精度を高める** を、操作できるダッシュボードにしたもの。

**`index.html` をブラウザで開くだけで動きます。** ビルドもサーバーもネットワーク接続も不要
（外部CDN参照ゼロ、チャートはすべてインラインSVG、写真はデータURIで内包）。

既存の統合Overviewダッシュボード（`sonysonpo.d-demo.app`）のIA・配色・語彙に合わせています。

---

## 7ページ構成

| | ページ | 役割 |
|---|---|---|
| ① | Market Overview | 15の仮想生活者群 × 未認知／認知／好意／見積／契約 で市場を俯瞰し、ストックの積み上がりを見る |
| ② | AIペルソナ一覧＋デプスインタビュー | 15群を一人の生活者として理解し、本人に質問する |
| ③ | ジャーニー再現シミュレーション | PULL接触から契約まで、人数の流れをリボンで追う |
| ④ | AIアイデアブラッシュアップ | 案リストから1案を選び、メッセージ・媒体別展開をAIとの壁打ちで具体化する |
| ⑤ | アイデア一括シミュレーション | 案リストから最大4案を選び、15群を総当たりで比較する |
| ⑥ | 事業インパクト・ROI評価 | 当期増分利益＋将来増分利益のPVを、PULL投資額で割ってROIに翻訳する |
| ⑦ | 学習ループ | 実測を入れて共鳴係数を更新し、次回予測に反映する |

ナビは `市場を見る → 顧客と効き方を理解する → 打ち手をつくる → 実行前に選ぶ → 学習して戻す`
の5ステージに束ねています。

## 計算モデル

```
好意率Lift(pt) = 施策の力 × コンテンツ親和度 × 保険関与度 × 媒体適合 × 接触量 × 共鳴係数
接触量         = 到達率 × (1 − e^(−頻度/4))          … 頻度の項は凹関数（飽和する）

好意者純増   = 母数 × 好意率Lift
サイト来訪増 = 好意者純増 × 来訪率Lift（好意の有無による差）
見積増       = 好意者純増 × 見積率Lift（好意の有無による差）
契約増       = 見積増 × 見積→契約率
増分利益     = 契約増 × 平均保険料 × 貢献利率

ROI = (当期増分利益 ＋ 将来増分利益のPV) ÷ PULL投資額
共鳴係数 ← 共鳴係数 × (実測リフト ÷ 予測リフト)      … ⑦の学習
```

**ご提案資料の検証済み連鎖をそのまま再現します。** 日向坂コンテンツ × 日向坂46好き×比較検討層
（100万人）で:

| | 本デモ | 資料 |
|---|---|---|
| 好意率Lift | ＋7.0pt（20.0% → 27.0%） | ＋7.0pt |
| 好意者純増 | ＋70,300人 | ＋70,000人 |
| サイト来訪増 | ＋35,150人 | ＋3.5万人 |
| 見積増 | ＋5,624件 | ＋5,600件 |
| 契約増 | ＋562件 | ＋560件 |
| 増分利益 | 約410.6万円 | 408.8万円 |

⑥は **ROI 123.3%** を再現します（資料記載「約123%」）。

## 数値の性格

- **開示値は1つだけ** — 貢献利率14.6%（＝100% − 正味損害率60.8% − 正味事業費率24.6%、
  ソニー損保2025年度決算）。
- それ以外の人数・率・金額は、資料上の仮定値か本デモの設計値。画面上でも精度バッジ
  （実測／推計／設計値）で区別しています。
- docomoデータは**集計・統計情報のみ**を使用する前提（個人ID連携なし）。この但し書きは
  スコープバーに常時表示しています。

## 保守

デモ本体は `index.html` 1枚です。写真の差し替えと動作検証だけ、`src/` にツールを置いています。

```bash
cd src && npm install

node embed-photos.mjs        # src/photos/ の画像を index.html へ焼き込む
node embed-photos.mjs --clear # 写真を外して絵文字アバター／SVGに戻す
node check.mjs               # 7ページ × 3幅で検証（JSエラー・横スクロール・資料値の再現）
node check.mjs --shots /tmp/shots   # スクリーンショットも保存
```

- `src/photos/<生活者群のID>.jpg` … ペルソナ写真（例 `camp-comp.jpg` ＝ キャンプ好き × 比較検討層）
- `src/photos/ideas/<案ID>.jpg` … 施策案のキービジュアル（`1.jpg` 〜 `6.jpg`）
- 切り出し位置は `embed-photos.mjs` の `FOCUS` / `IDEA_FOCUS` で調整できます

`check.mjs` は7ページすべてを 1280 / 1500 / 1680px で開き、**JSエラー・横スクロール・描画の空振り**を
検出したうえで、**ROI 123.3% と例示ケース（好意率Lift +7.0pt／サイト来訪 +35,150人／
見積 +5,624件／契約 +562件）を再現できているか**を検算します。1つでも外れると終了コード1で落ちます。
