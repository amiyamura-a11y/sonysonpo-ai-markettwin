# ペルソナ写真

ここに画像を置いて `node demo/embed-photos.mjs` を実行すると、顔中心の正方形に
トリミングされて単一HTMLへ焼き込まれます（外部ファイル参照は増えません）。

## ファイル名

**`<生活者群のID>.jpg`** で保存してください。IDは「嗜好-保険との関係」です。

| 嗜好 | | 保険との関係 | |
|---|---|---|---|
| `idol` | アイドル好き | `new` | 純新規 |
| `hinata` | 日向坂46好き | `major` | 大手志向層 |
| `mahjong` | 麻雀好き | `comp` | 比較検討層 |
| `camp` | キャンプ好き | | |
| `game` | ゲーム好き | | |

例：`camp-comp.jpg` ＝ キャンプ好き × 比較検討層（石井 直樹）

15人分すべて揃える必要はありません。**写真が無いペルソナは嗜好群の絵文字タイルに
フォールバック**します。

## 顔の位置の調整

`demo/embed-photos.mjs` の `FOCUS` に、画像内の顔の位置（`fx`/`fy`＝0〜1の相対座標）と
`zoom`（切り出す正方形の大きさ／短辺比）を書きます。引きの絵ほど `zoom` を小さくすると、
40px のアバターでも人物が読めます。書かなければ中央寄りで切り出します。

## 使い方

```bash
node demo/embed-photos.mjs                  # 既定：360px / JPEG q78
node demo/embed-photos.mjs --size 480       # 大きめに焼く
node demo/embed-photos.mjs --clear          # 写真を全部外して絵文字に戻す
```

写真はここ（`demo/photos/`）にも残しますが、デモHTMLは写真を内包しているので
配布時はHTML1枚で完結します。
